# docs/

- `QUESTIONS.md` — the research questions, registered before the results.
- `REPORT.md` — the report.
- `SLIDES.md` — the slide plan: what each slide has to carry, and the kinds of question
  you will be asked. Fill it in as you build the deck.
- `slides.pdf` — the presentation, at most 15 slides. **Put it here**, not in the root.

The slides must include a slide titled **"What could confound this?"**.
