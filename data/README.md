# data/

**Niente di quello che sta qui viene committato**: `.gitignore` esclude la cartella.

Sostituite questo file con le istruzioni per procurarsi il dataset assegnato, in modo che
chi clona il repository possa eseguire il notebook dopo aver letto solo questo file:

- **da dove viene** e con quale **licenza** (l'e-mail di assegnazione lo dice);
- **quale file** scaricare e con che nome salvarlo qui dentro;
- **che cosa è una riga** — un paziente, un'ora di rilevazione, una transazione;
- **come sono stati raccolti**: un esperimento, un questionario, o l'osservazione di
  qualcosa che accadeva comunque. Da questo dipende che cosa potete concludere, e la
  Parte 1 ve lo chiede esplicitamente.

Se il dataset si scarica da un URL pubblico, uno script `download.py` di tre righe è il
modo più comodo di dirlo.
